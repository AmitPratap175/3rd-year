# 📝 Numerical Methods & Computational Physics in Python & MATLAB

This repository contains a collection of Python and MATLAB scripts for various numerical methods, computational physics problems, and scientific computing exercises. The code covers ODE/PDE solvers, eigenvalue problems, root-finding algorithms, numerical integration, and more.

## 📂 Repository Structure

The repository is organized into the following categories:

### 1️⃣ **Eigenvalue Problems** (`1_eigenvalue_problems/`)
- **`18ms175_eigenclass3`**: Solves a specific eigenvalue problem from classwork.
- **`1D SHO solution`**: Solves the Schrödinger equation for the simple harmonic oscillator.

### 2️⃣ **Ordinary Differential Equations (ODEs)** (`2_ordinary_differential_equations/`)
- **`AdaptiveRK4_Adam-Moultoun_and_Bashforth`**: Implements adaptive Runge-Kutta (RK4), Adams-Moulton, and Adams-Bashforth methods.
- **`ODE_Euler Algorithm_Heat equation`**: Solves ODEs using Euler’s method and applies it to the heat equation, including a Crank-Nicolson implementation.
- **`ODE_Huen_RK4_methods`**: Solves ODEs using Heun’s and RK4 methods.

### 3️⃣ **Numerical Methods & Root Finding** (`3_numerical_methods_and_root_finding/`)
- **`Bisection_Newton Rhapson_Regulafalsi_Secant`**: Contains a MATLAB implementation of the bisection method.
- **`Numerical Analysis MATLAB`**: A collection of MATLAB scripts for various numerical methods, including Gaussian elimination, interpolation, Newton’s method, and more.

### 4️⃣ **Numerical Integration** (`4_numerical_integration/`)
- **`Numerical integration`**: Implements trapezoidal rule, Simpson’s rule, and other numerical integration techniques in Python.

### 5️⃣ **Special Topics** (`5_special_topics/`)
- **`IEEE 754 conversion`**: Python scripts for floating-point conversion following IEEE 754 standards.
- **`escape velocity probability`**: Computes the probability of particles escaping based on given velocity distributions.

### 6️⃣ **Numerov Method** (`6_numerov_method/`)
- **`Numerov_classwork4`**: Implements the Numerov method for solving second-order differential equations.

### 7️⃣ **Game Simulation** (`7_game_simulation/`)
- **`snake and ladders`**: A Python implementation of the Snake and Ladders game in both single-player and two-player versions.

## 🚀 How to Use

1.  Clone the repository:
    ```sh
    git clone https://github.com/yourusername/your-repo.git
    ```
2.  Navigate into the project directory of interest, e.g.:
    ```sh
    cd "1_eigenvalue_problems/1D SHO solution/"
    ```
3.  Run the Python scripts or MATLAB files as needed. For the refactored Python example, you would run:
    ```sh
    python q1.py
    ```

This repository is updated casually with new solutions, optimizations, and explorations. Perfect for practice and learning!
