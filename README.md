# 📝 Numerical Methods & Computational Physics in Python & MATLAB

This repository contains a collection of Python and MATLAB scripts for various numerical methods, computational physics problems, and scientific computing exercises. The code covers **ODE/PDE solvers, eigenvalue problems, root-finding algorithms, numerical integration, and more**.  

## 📂 Repository Structure  

### 1️⃣ **Eigenvalue Problems**
#### `18ms175_eigenclass3`
- `Classwork3.pdf` – Problem statement  
- `q1.py` – Python script for solving the given eigenvalue problem  

#### `1D SHO solution`
- **Solves the Schrödinger equation for the simple harmonic oscillator**
- `q1.py, q2.py, q3.py, q4.py` – Python implementations  
- `*.png` – Plots of eigenfunctions and energy values  
- `WorkSheet1.pdf` – Problem set  

### 2️⃣ **Ordinary Differential Equations (ODEs)**
#### `AdaptiveRK4_Adam-Moultoun_and_Bashforth`
- Implements **adaptive Runge-Kutta (RK4), Adams-Moulton, and Adams-Bashforth methods**  
- `q1_b.py, q1_c.py, q2.py, q3.py` – Python scripts  
- `ADG_ps2.pdf` – Problem statement  

#### `ODE_Euler Algorithm_Heat equation`
- **Solves ODEs using Euler’s method and applies it to heat equations**  
- `q1(a).py, q1(b).py, q1(c).py, q3(a).py, q3(b).py, q3_cranknickolson.py` – Python implementations  
- `*.dat` – Data files  
- `ADG_ps3.pdf` – Problem set  

#### `ODE_Huen_RK4_methods`
- **Solves ODEs using Heun’s and RK4 methods**  
- `q1.py, q2.py, q3.py, q4.py` – Python implementations  
- `ODE.pdf, ADG_ps1.pdf` – Problem descriptions  

### 3️⃣ **Numerical Methods & Root Finding**
#### `Bisection_Newton Rhapson_Regulafalsi_Secant`
- `bisection.m` – MATLAB implementation of the bisection method  

#### `Numerical Analysis MATLAB`
- MATLAB scripts for **bisection, Gaussian elimination, Newton’s method, interpolation, Simpson’s rule, and more**  
- Organized into subfolders:  
  - `gausselimination/`
  - `interpolate/`
  - `newton method/`
  - `regulafalsi/`
  - `simpsons/`
  - `trapezoidal/`  

### 4️⃣ **Numerical Integration**
#### `Numerical integration`
- Implements **trapezoidal rule, Simpson’s rule, and other numerical integration techniques**  
- `q1.py, q2.py, q3.py, q4.py` – Python scripts  
- `*.png` – Plots of integration results  

### 5️⃣ **Special Topics**
#### `IEEE 754 conversion`
- **Python scripts for floating-point conversion following IEEE 754 standards**  
- `q1.py, q2.py`  

#### `escape velocity probability`
- `q1.py` – Computes the probability of particles escaping based on given velocity distributions  

### 6️⃣ **Numerov Method**
#### `Numerov_classwork4`
- Implements the **Numerov method for solving second-order differential equations**  
- `q1_numerov.py, q1.py` – Python scripts  
- `q1.png` – Resulting plot  

### 7️⃣ **Game Simulation**
#### `snake and ladders`
- Python implementation of the **Snake and Ladders** game  
- `snake_1player.py` – Single-player version  
- `snake_1player_uniform.py` – Uniform probability version  
- `snake_2player.py` – Two-player version  
- `board.png` – Game board image
